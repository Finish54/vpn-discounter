# VPN Discounter — лендинг

Статика без сборщиков и фреймворков. Заливается в корень любого хостинга как есть
(Apache/nginx/любой шаред — так же, как старый PHP-сайт). Никакого `npm run build`.

```
vpn-discounter/
├── index.html                 вся разметка + inline SVG-спрайт иконок
├── README.md
└── assets/
    ├── css/style.css
    ├── js/i18n.js             словарь RU/EN + список серверов
    ├── js/worldmap.js         маска суши 150×44 (Natural Earth 110m)
    ├── js/app.js              вся логика
    ├── img/                   стоп-кадр, постер, og, favicon
    └── video/                 promo.mp4 (1.2 МБ) + promo-mobile.mp4 (0.5 МБ)
```

## Что поменять перед публикацией

| Что | Где | Сейчас |
|---|---|---|
| **Ссылка на бота** | `assets/js/app.js`, строка 8 — `const TG_BOT` | `https://t.me/YOUR_BOT` |
| Юзернейм в футере | `index.html`, блок «Контакты» | `@vpn_discounter` |
| Почта поддержки | `index.html`, `mailto:` | `support@vpndiscounter.ru` |
| Соглашение и политика | `assets/js/i18n.js`, ключи `doc.terms.b` / `doc.privacy.b` | текст-заглушка в модалке |
| Ссылки на App Store | `index.html`, шаг 01 | ведут на Happ Proxy Utility |
| Домен в og-тегах | `index.html`, `<meta property="og:image">` | относительный путь |

`TG_BOT` подставляется во **все** элементы с классом `.js-cta` (10 штук: шапка, герой,
три тарифа, шаг 02, финальный CTA, две ссылки в футере) — менять нужно только в одном месте.

## Языки

Переключатель RU/EN в шапке. Русский — язык по умолчанию, выбор запоминается в
`localStorage` (`vpnd_lang`).

Перевод живёт в `assets/js/i18n.js`: объекты `I18N.ru` и `I18N.en`, ключ = значение
атрибута `data-i18n` в разметке. Для атрибутов (например `<meta content>`) добавляется
`data-i18n-attr="content"`.

Добавить третий язык: дописать объект `I18N.xx` и кнопку
`<button class="lang__btn" data-lang="xx">XX</button>` в блок `.lang` — больше ничего.

## Зависимости (CDN)

- GSAP 3.12.5 + ScrollTrigger — анимации по скроллу
- Lenis 1.1.13 — плавный скролл
- Google Fonts — Manrope

Все три подключены с `defer` и **не обязательны**: если CDN недоступен, страница
отрисуется полностью, просто без плавностей (`hasGSAP === false` → все reveal-блоки
видны сразу, иконки сервисов зажжены, шаги установки переключаются по клику).
Если хостинг должен быть автономным — скачайте библиотеки в `assets/js/vendor/` и
поправьте три `<script src>` в конце `index.html`.

## Определение IP

`GEO_API` в `app.js` (строка 12) — `https://ipapi.co/json/`, бесплатный лимит ~1000
запросов в сутки без ключа. При отказе или блокировке запроса блок показывает
«Не удалось определить сеть», всё остальное продолжает работать.

Альтернативы с той же формой ответа: `https://ipwho.is/`, `https://ipinfo.io/json?token=…`.
Нужны поля `ip`, `city`, `country_name`.

> Тумблер — демонстрация. Он не поднимает туннель, а показывает, как выглядит подмена
> IP. Дисклеймер лежит в словаре под ключом `toggle.hint` (сейчас в вёрстке не выведен —
> вставьте, если нужно явное предупреждение).

## Производительность и доступность

- Вес первого экрана: ~0.5 МБ на мобильном (`promo-mobile.mp4`), ~1.2 МБ на десктопе.
  Ролик выбирается по `innerWidth < 760` и грузится через `src`, назначаемый из JS,
  поэтому на мобильном десктопная версия не скачивается вообще.
- Карта мира — 2102 точки на `<canvas>`, а не 2102 DOM-узла.
- Иконки сервисов — inline SVG в спрайте, внешних картинок нет.
- `prefers-reduced-motion: reduce` выключает видео, лучи, шум, свечение курсора и все
  переходы; иконки сервисов и reveal-блоки сразу в финальном состоянии.
- Клавиатура: skip-link, `role="switch"` с `aria-checked` на тумблере, точки карты —
  настоящие `<button>` с `aria-label`, Escape закрывает модалку и мобильное меню.

## Проверка

`_smoke.js` в родительской папке — тест на jsdom (30 проверок: CTA, переключение языка,
слайдер тарифов, тумблер, модалка, меню). Запуск:

```bash
npm i -D jsdom
node _smoke.js
```

Визуальную проверку в реальном браузере (десктоп + мобильный) нужно сделать вручную —
в песочнице сборки браузер недоступен.
